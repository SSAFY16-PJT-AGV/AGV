# FastAPI 격리 시뮬레이션 연결 계획

설계 v0.2와 기존 제안에 따라 실제 장비를 제어하지 않는 단일 프로세스 로컬 시뮬레이션을 기본 비활성으로 연결한다. HTTP 계약은 제안 문서로 먼저 기록한다.

1. SQLite, 고정 로봇·작업·세션 매핑, 구독 수신기 및 별도 발행 클라이언트를 묶는 런타임을 구현한다. 로컬 전용 브로커와 명시적 설정을 요구하고, 중복 프로세스를 차단한다. 실패와 종료 시 연결을 정리하며 재시작 시 증명과 주문 자동 복구를 금지한다.
2. 작업 생성·첫 예약·발행, 복구 확인, 이벤트 재처리, 대기 주문 발행을 인증된 로컬 HTTP 경로에 연결한다. 입력은 엄격히 검증하고 내부 예외를 노출하지 않는다.
3. FastAPI 수명주기에 런타임을 붙이고, 기본 실행은 기존 관측 서비스만 실행한다. 설정 오류와 시작 실패는 정리 후 실패한다.
4. 격리 MQTT 브로커, 가짜 로봇, HTTP 요청으로 첫 주문부터 이탈·중복·복구를 검증하고 전체 테스트를 실행한다. 설정과 실제 로봇 사용 제한을 문서화한다.

검토 중점: 미승인 작업·세션, 연결 끊김과 구독 준비, 중복 실행, 재시작 전 증명의 재사용, uncertain 주문 자동 재발행, 하나의 DB에 여러 프로세스 기동, 종료 중 발행 및 예외 시 자원 정리.
