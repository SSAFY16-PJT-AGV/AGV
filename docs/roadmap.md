스마트 마트 물류 자동화 시스템 · 검토 반영본

기준: 기존 「주차.docx」, [설계 문서 v0.2](design.md), GitHub Issue #1 / 계획 시작일: 2026.11.02 / 일정 검토 반영: 2026.11.02

## 1. 프로젝트 목표 및 운영 원칙

판매대 재고 부족 감지 → 작업 생성 → AGV 2대 물품 운반·충돌 방지 → 재고 갱신 → Unreal 디지털 트윈 관제를 연결한다.

11월(1~4주차)은 실물 로봇 주행·매핑·상하차와 실측 데이터 확보, 12월(5~8주차)은 시뮬레이터·로그 기반 통합 및 고도화를 우선한다. ROS 대신 Python/Waveshare 제어 코드와 MQTT·JSON 통신을 사용하는 것은 설계 문서 v0.2의 제안이며 팀 확정이 필요하다.

W4는 실물을 쓸 수 있는 마지막 주이므로 실물 검증 전용 주로 비워 둔다. 실물 없이 개발할 수 있는 작업(충돌 방지 로직, 가상 AGV, 비전 데이터 수집)은 W2~W3으로 앞당기고, 매핑은 수동 주행 기반 파이프라인(W3)을 먼저 완성한 뒤 자율 탐색(W4)을 얹는다.
