# 가상 우회 구간 준비

`SimRuntime(..., field_simulation=True, reroute_transitions=True)`는 격리된 가상
로봇의 검증된 대기 상황에 한해 `prepare_reroute(task_id)`를 허용한다. 이 호출은
기존 후보 계산의 동일한 로봇·수신기·복구 게이트·SQLite 트랜잭션 안에서
맵, 정지 방향, 대기 이벤트, 전체 로봇 점유와 우회 후보를 다시 확인한다.

준비에 성공하면 기존 점유와 후보 첫 구간의 점유 합집합을 **기존**
`allocation_occupancy`에 원자적으로 기록하고 부모 시퀀스·이벤트·경로와
새 세대 1의 고유 전환 ID를 남긴다. 다른 할당도 같은 점유를 보므로 신규
구간을 선점할 수 없다. 전역 무결성 검사는 경로·이벤트·점유의 조합이
정확히 일치하는지 확인하고, 손상이 보이면 모든 필드 할당을 차단한다.

**이 기능은 명령을 발행하거나 로봇을 움직이지 않는다.** 로봇 수락 증거,
발행 결과 불명의 복구 및 세대 전환은 아직 구현되지 않았다. 준비 중 기존
명령 수락과 기존 이벤트 진행은 차단하고 기존·신규 점유를 모두 유지한다.
실패하면 트랜잭션 전체를 되돌리며, 서버나 브로커가 중단되거나 재시작 시
옵션을 끄더라도 이미 준비된 점유는 지우지 않는다. 현재 준비를 자동 취소하거나
완료하는 API는 없다. 새로운 작업이 필요한 경우 격리 테스트의 새 DB·새
프로세스를 사용하고 기존 데이터는 보존한다.

이 작업은 실물 위치·후단 이탈·로봇 인증 또는 안전의 증거가 아니다.
실물 장비와 공용 브로커에는 연결하지 않는다. 다음 구현 단계는
[가상 경로 변경 인계 설계](sim_reroute_generation_design.md)를 참고한다.

격리 MQTT와 일반·가상 함대 저장소의 두 AGV 경합, 롤백·손상·재시작 시험:

```powershell
$env:AMQTT_TEST_PATH = (Resolve-Path .venv\broker-deps).Path
.\.venv\Scripts\python.exe -m unittest server.tests.test_sim_reroute_reservation -q
```
